JOUABILITE 0-5

+1 SG/NP/statut OK.

+1 noyau A/B/C sain.
+1 aucun favori central fragile/sous-paye.

PROBA_BASSE
Score : +1 forme ; +1 3DERMUS 3-13 ; +1 J/E >=0 ; +1 aptitude ; +1 marche stable/steam coherent ; -1 faute/0 lourd ; -1 rentree/parcours parfait ; -2 fautif chronique. Score <=1 refus. 2 simulation/micro. 3 CP_SEC/SP. 4+ CP3 si proxy OK. Comparer a proba_basse_calibration. 3DERMUS >=25 rouge. Deux chevaux >=19 dans un panier = refus. Top nom seul = sous-paiement.

CP_SEC / CP3
CP reel si >=8 partants, SG/NP OK, moteur rejouable, split valide, proxy/fallback declare, erreur suivie, segment non ROUGE/ND, volatilite acceptable, proba_basse defendable, aucun kill-switch.
CP_SEC prioritaire si une paire domine, CP3 dilue, segment ORANGE ou volatilite instable.
CP_SEC domine si au moins deux conditions : ROI_SEC >= ROI_CP3 ; drawdown_SEC < drawdown_CP3 ; ratio_median_SEC >= ratio_median_CP3 ; CP3 souvent remboursant ; une seule paire concentre la probabilite ; deux paires CP3 ont R_prudent <3,00.
Si CP_SEC domine : CP3 refuse.
Si CP3 bat CP_SEC par gros retour isole : simulation.
CP3 reel seulement si ROI median, ratio median et drawdown acceptables, >=2 paires defendables, R_prudent >=3,60 sur une paire plausible et CP_SEC non superieur.

SP / DUTCHING / 2SUR4
SP standard si SP_min visible, segment_SP UTILISABLE, retour couvrant, proba_basse >1,20/SP_min, >=3 faits independants, non dependant d'un parcours parfait.
Micro-SP = 1 EUR max, suivi separe.
Sans sp_calibration_segments : pas de SP standard.
Dutching : 2 chevaux max ; chaque SP couvre seul l'exposition ; jamais deux profils fautifs, rentrants ou dependants du meme scenario.
2SUR4_EXP : experimental, 1 EUR max, >=10 partants, ancre propre, proxy/rapport exploitable, proba_basse_top4 >1,30/R_prudent.
